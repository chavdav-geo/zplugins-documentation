Esta página detalla la estructura y el contenido de los archivos de configuración generados en `/plugins/zVoidChests/`.

---

## 📂 Estructura de Directorios

```text
plugins/zVoidChests/
├── config.yml            # Configuración general, hologramas, base de datos y precios de sub-mejoras.
├── chests.yml            # Definición de Tiers, ítems, lores, costos de mejora y habilidades.
├── prices.yml            # Tabla de precios interna (cuando shop-plugin es "none").
├── database.db           # Base de datos SQLite local (cuando storage.type es "SQLITE").
├── lang/                 # Archivos de traducción de idiomas.
│   ├── es_ES.yml         # Español (ES)
│   ├── en_US.yml         # Inglés (US)
│   ├── fr_FR.yml         # Francés (FR)
│   └── de_DE.yml         # Alemán (DE)
└── menus/                # Archivos de diseño de menús interactivos GUI.
    ├── main-menu.yml     # Menú principal del cofre.
    ├── upgrades-menu.yml # Menú de sub-mejoras.
    ├── filter-menu.yml   # Menú de filtro Whitelist/Blacklist.
    ├── members-menu.yml  # Menú de gestión de miembros.
    └── admin-tp-menu.yml # Menú administrativo de teletransporte a cofres.
```

---

## 📝 1. `config.yml` (Plantilla Anotada)

```yaml title="plugins/zVoidChests/config.yml"
general:
  prefix: "&#00E5FF&l[zVoidChests] &r" # Prefijo del plugin en chat
  language: "es_ES"                    # Idioma activo: es_ES, en_US, fr_FR, de_DE
  shop-plugin: "economyshopgui"        # Proveedor de precios: "economyshopgui", "shopgui+", "none"
  webhook-url: "https://discord.com/api/webhooks/..." # URL de webhook de Discord para logs
  auto-save-interval: 300              # Intervalo de guardado en segundos (5 minutos)
  default-max-chests: 5                # Límite por defecto si no tiene permiso voidchest.limit.<n>

fuel:
  enabled: true                        # Activar o desactivar requerimiento de combustible
  initial-free-hours: 2                # Horas gratis al colocar el cofre
  cost-per-hour: 1000.0                # Costo por hora de combustible

auto-sell:
  interval: 5                          # Frecuencia de venta en segundos
  sell-particles: true                 # Efectos visuales de partículas
  notify-player: true                  # Notificaciones resumidas en chat
  notification-cooldown: 30            # Cooldown entre notificaciones en segundos

collector:
  instant-collection: true             # Recolección instantánea
  vacuum-particles: true               # Partículas de absorción de ítems

holograms:
  enabled: true                        # Activar hologramas sobre el cofre
  height-offset: 1.25                  # Altura del holograma sobre el cofre
  lines:
    - "&#00E5FF&l{tier_name}"
    - "&7Dueño: &f{owner}"
    - "&7Estado: {status}"
    - "&7Gasolina: &e{fuel_time}"
```
