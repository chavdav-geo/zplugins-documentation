## ⚡ Características Principales de Nuestros Plugins

* 🚀 **Alto Rendimiento:** Diseñados y testeados para servidores de alta demanda (Paper, Purpur y Spigot) minimizando el consumo de CPU y memoria.
* 📦 **Compatibilidad Multi-Versión:** Soporte para versiones modernas de Minecraft (`1.18` hasta `1.21+`).
* 💾 **Almacenamiento Confiable:** Soporte tanto para bases de datos locales (`SQLite` / `H2`) como remotas (`MySQL` / `MariaDB`) con guardado asíncrono.
* 🎨 **Personalización Total:** Mensajes en múltiples idiomas, menús GUI configurables y soporte de colores HEX / MiniMessage.
